# metal-spec-extractor

Извлечение спецификаций металлопроката из PDF-документов в структурированный формат (Excel/CSV/JSON).

Программа автоматически распознаёт таблицы спецификаций металлоконструкций во входных PDF-файлах, определяет вложенную иерархию позиций (сборки → детали), извлекает характеристики проката и сохраняет результат в удобном для обработки виде.

## Возможности

- **Извлечение таблиц из PDF** — автоматическое обнаружение табличных структур на страницах документа
- **Поддержка вложенной структуры** — распознавание иерархии позиций (1 → 1.1 → 1.1.1), определение сборочных единиц и деталей
- **Интеллектуальный маппинг колонок** — автоматическое сопоставление заголовков таблицы с полями спецификации по ключевым словам
- **Объединение строк-продолжений** — корректная обработка переносов текста на следующую строку
- **Пост-обработка значений** — очистка марок стали, нормализация числовых значений массы и количества
- **Вывод в нескольких форматах** — Excel (с форматированием и сводным листом), CSV (с разделителем `;`), JSON
- **Сводный лист в Excel** — автоматически формируется лист «Сводка» с суммарной массой по маркам стали и профилям
- **Работа с многостраничными PDF** — таблицы с разных страниц объединяются в общий результат
- **Русский интерфейс CLI** — все сообщения, справка и логи на русском языке

## Установка

### Зависимости

- Python 3.10+
- pdfplumber >= 0.10.0
- openpyxl >= 3.1.0
- pandas >= 2.0.0
- click >= 8.1.0

### Установка из исходников

```bash
git clone https://github.com/sithortodox/metal-spec-extractor.git
cd metal-spec-extractor
pip install -r requirements.txt
```

## Использование

### Базовый запуск

```bash
# Извлечение в Excel (формат по умолчанию)
python3 -m src.cli спецификация.pdf

# Явное указание выходного файла
python3 -m src.cli спецификация.pdf -o результат.xlsx
```

### Форматы вывода

```bash
# Excel (.xlsx) — с форматированием, автофильтром и сводным листом
python3 -m src.cli спецификация.pdf -o результат.xlsx -f excel

# CSV (.csv) — разделитель «точка с запятой», кодировка UTF-8 с BOM
python3 -m src.cli спецификация.pdf -o результат.csv -f csv

# JSON (.json) — массив объектов, UTF-8, с отступами
python3 -m src.cli спецификация.pdf -o результат.json -f json
```

### Стратегии обнаружения таблиц

Если таблицы определяются некорректно, можно сменить стратегию:

```bash
# По линиям (по умолчанию) — для таблиц с видимыми линиями сетки
python3 -m src.cli спецификация.pdf --strategy lines

# По текстовым блокам — для таблиц без линий сетки
python3 -m src.cli спецификация.pdf --strategy text

# Строгий режим по линиям
python3 -m src.cli спецификация.pdf --strategy lines_strict
```

### Подробный вывод

```bash
python3 -m src.cli спецификация.pdf -v
```

### Справка

```bash
python3 -m src.cli --help
```

## Структура выходных данных

Каждая позиция спецификации содержит следующие поля:

| Поле | Описание |
|------|----------|
| `position` | Позиция по спецификации (1, 1.1, 1.2 и т.д.) |
| `parent_position` | Позиция родительской сборки |
| `level` | Уровень вложенности (0 = сборка, 1 = деталь) |
| `name` | Наименование |
| `designation` | Обозначение чертежа/документа |
| `profile` | Профиль / сечение проката |
| `steel_grade` | Марка стали |
| `quantity` | Количество, шт. |
| `length` | Длина, мм |
| `mass_single` | Масса единицы, кг |
| `mass_total` | Масса общая, кг |
| `note` | Примечание |
| `page_number` | Номер страницы PDF |

## Формат Excel

Выходной Excel-файл содержит два листа:

1. **Спецификация** — полный перечень позиций с:
   - Цветовой подсветкой сборочных строк (синий фон, жирный шрифт)
   - Автофильтром по всем колонкам
   - Закреплённой строкой заголовков
   - Настроенной шириной колонок

2. **Сводка** — сводная информация:
   - Количество сборок и деталей
   - Общая масса по сборкам
   - Сводка по маркам стали (марка → суммарная масса)
   - Сводка по профилям проката (профиль → суммарная масса)

## Архитектура проекта

```
metal-spec-extractor/
├── src/
│   ├── __init__.py          # Пакет
│   ├── __main__.py          # Точка входа python -m src
│   ├── extractor.py         # Извлечение таблиц из PDF (pdfplumber)
│   ├── parser.py            # Парсинг вложенной структуры спецификации
│   ├── output.py            # Сохранение в Excel/CSV/JSON
│   └── cli.py               # Командный интерфейс (click)
├── generate_sample.py       # Генератор тестового PDF с кириллицей
├── requirements.txt         # Зависимости
├── pyproject.toml           # Конфигурация проекта
└── .gitignore
```

### Модуль extractor.py

Извлекает таблицы из PDF с помощью библиотеки pdfplumber. Определяет строки заголовков по ключевым словам спецификации металлопроката, очищает текст ячеек, обрабатывает объединённые ячейки.

### Модуль parser.py

Преобразует «сырые» строки таблиц в структурированные позиции спецификации (`SpecItem`). Определяет:
- Уровень вложенности позиции по формату номера (1 → уровень 0, 1.1 → уровень 1)
- Сборочные единицы по отсутствию профиля/марки стали или по ключевым словам
- Строки-продолжения (перенос текста на следующую строку)
- Связи «деталь → сборка» через поле `parent_position`

### Модуль output.py

Формирует выходные файлы в трёх форматах. Excel-вывод включает форматирование, автофильтр и сводный лист с группировкой по маркам стали и профилям.

## Поддерживаемые форматы спецификаций

Программа ориентирована на типовые спецификации металлоконструкций по ГОСТ/СНиП со следующими колонками:

- Позиция (Поз., №)
- Наименование
- Обозначение
- Профиль / Сечение
- Марка стали
- Количество (Кол-во)
- Длина
- Масса единицы
- Масса общая
- Примечание

Допускаются вариации заголовков (сокращения, синонимы) — маппинг осуществляется по вхождению подстроки.

## Генератор тестового PDF

Для проверки работоспособности можно сгенерировать тестовый PDF:

```bash
pip install reportlab
python3 generate_sample.py
```

Будет создан файл `test_spec.pdf` с двухстраничной спецификацией, содержащей 5 отправочных марок и 30 позиций. Шрифт — DejaVuSans (поддержка кириллицы).

## Ограничения

- Для корректного извлечения таблиц PDF должен содержать **настоящие текстовые слои** (не скан-копии)
- Качество распознавания зависит от структуры PDF: наличие линий сетки, выравнивание колонок
- Если заголовки таблицы не распознаны автоматически, используется маппинг по умолчанию
- При сложных объединённых ячейках часть данных может потребовать ручной корректировки
